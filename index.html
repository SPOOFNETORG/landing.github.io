How it works

Six steps from
camera to verdict.

The entire pipeline runs client-side. From browser permission request to final liveness decision, with no round trips to a server.

01

Camera permission

The browser's native permission dialog requests camera access. SpoofNet asks only for what it needs.

Browser API
02

Live feed capture

A short sequence of frames is captured from the webcam stream. Frames are processed in memory only.

MediaStream
03

Face detection

A lightweight pass detects and crops the face region, normalizing it to a fixed input size.

On-device
04

Liveness inference

The model runs entirely in-browser via WebAssembly. Analyzes depth, texture, and micro-motion signals.

WASM / WebGL
05

Confidence scoring

The model outputs a liveness confidence score.

Configurable
06

Verdict in <20ms

A real/spoof verdict is returned to your application.

Instant
